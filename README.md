# Padel Discovery AI MVP

Padel Discovery AI is a two-service Django + Next.js MVP for discovering padel courts, coaches, and tournaments through browsing and AI-assisted natural language search.

## Run

```bash
docker compose up --build
```

Open:

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000/api/schema/
- Django admin: http://localhost:8000/admin/
